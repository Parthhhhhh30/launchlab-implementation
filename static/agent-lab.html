03 / WHAT THIS DOES NOT CLAIM

Useful evidence.
Clear boundaries.

Real model calls are made server-side only when an explicitly configured free-tier API key is available. All records are fictional. No Metaview agent or ATS is connected.

Models can return convincing unsupported explanations. Citation IDs are validated against supplied facts, but semantic correctness still requires human inspection. There are no automated employment decisions, candidate rankings or live customer claims.
